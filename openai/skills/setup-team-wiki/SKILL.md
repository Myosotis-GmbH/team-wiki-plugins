# Set up Team Wiki

Read [the shared operating contract](../../references/operating-contract.md), then follow **Setup** in [the shared workflows](../../references/workflows.md).

Use the required Atlassian app and discover its supported operations. Resolve a supplied root or `Confluence wiki: <url>` in project instructions before asking for missing details. Reuse either plugin's existing pages and conventions; record shared configuration in Confluence. Return verified root/rules links and any remaining setup work.
