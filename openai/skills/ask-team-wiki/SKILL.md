# Ask the team wiki
Read ../../references/operating-contract.md first.

1. Resolve the team's space, read Rules and Index, then retrieve relevant current knowledge pages and source records. Search within scope and follow useful cross-references. Read full passages supporting material claims; snippets and titles are insufficient.
2. Answer directly with links to exact supporting pages and source records. Separate established facts, contested claims, inference, and unknowns. Include source dates when freshness matters. If pages disagree, describe both and the evidence needed to decide. An empty search is not proof that no answer exists.
3. Prefer accumulated synthesis, but check underlying evidence for critical or contradictory claims. Clearly identify inaccessible sources, pagination limits, or incomplete coverage. Do not invent citations or claim a team decision merely because one person's note says it.
4. A normal question causes no Confluence writes or query log. If the user also asks to save the answer, or an explicit configured writeback instruction applies, create/update a Synthesis page with provenance, related links, metadata, Index entry and Activity record under the same guarded write/review policy as ingestion. New reasoning is labeled inference.
5. If the user asks a cross-team question, bind each explicitly authorized space independently and preserve audience restrictions; do not silently aggregate restricted answers into a broadly visible page.
