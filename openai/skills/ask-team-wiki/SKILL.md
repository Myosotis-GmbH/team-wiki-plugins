# Ask the team wiki

Read [the shared operating contract](../../references/operating-contract.md), then follow **Ask** in [the shared workflows](../../references/workflows.md).

Use the required Atlassian app. Resolve the root from the request or a verified project pointer. Answer from accumulated synthesis with supporting evidence, preserving uncertainty and audience boundaries. Ordinary questions cause no writes or query logs. Offer to save reusable analysis; write it only with corresponding authorization.
