# Ingest team sources

Read [the shared operating contract](../../references/operating-contract.md), then follow **Ingest** in [the shared workflows](../../references/workflows.md).

Use the required Atlassian app. Resolve the root from the request or a verified project pointer. Deduplicate source versions, resume partial work, preserve immutable source records and human text, and route disputed changes through review. Requested ingestion includes routine source, index, and activity writes. Return verified changes and pending proposals with links.
