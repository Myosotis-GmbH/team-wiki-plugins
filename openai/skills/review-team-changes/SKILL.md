# Review team changes

Read [the shared operating contract](../../references/operating-contract.md), then follow **Review** in [the shared workflows](../../references/workflows.md).

Use the required Atlassian app. Assessment is read-only. Any member of the wiki's team may review another member's proposal; no designated reviewer role is required. Verify the approving member's team membership, independence from the proposed changes, explicit approval, and current page versions before applying proposals. Preserve human edits and dissent; record partial application so retries skip completed work safely. Return applied changes and unresolved decisions with links.
