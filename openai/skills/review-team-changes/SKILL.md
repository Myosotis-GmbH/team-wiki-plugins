# Review team changes

Read [the shared operating contract](../../references/operating-contract.md), then follow **Review** in [the shared workflows](../../references/workflows.md).

Use the required Atlassian app. Assessment is read-only. Verify reviewer authority, approval evidence, and current page versions before applying proposals. Preserve human edits and dissent; record partial application so retries skip completed work safely. Return applied changes and unresolved decisions with links.
